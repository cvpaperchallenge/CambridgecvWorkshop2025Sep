# 2026-11-12 Nodeセキュリティ更新

Node 24.22.3（同じ24系列）へ更新する。Dockerfileとdev/CI Composeを公式multi-arch digestに固定し、ローカル用.node-versionも一致させる。
公式根拠: https://nodejs.org/en/blog/release/v24.22.3
HTTP/2・TLS・証明書検証等の修正を含む。サイトが静的配信でも開発・ビルドのNodeは別に保守する。

実Node 24.22.2で `node environments/check-runtime-security.mjs` が最低修正版違反で失敗（RED）。24.22.3ではBrotli往復も含め成功（GREEN）。Dockerビルドも同じ検査を実行する。
独立worktreeでyarn install --frozen-lockfile、yarn lint、yarn build成功。依存lock・本文・既存ローカルnode_modulesは変更しない。
Dockerでの結果はPRに記録する。過去イメージや既存作業環境は自動移行されない。レビュー・マージ後に新規ビルドしてから利用する。
本番デプロイ・既存コンテナの置換は未実施。今回のPRはマージしない。

最終ローカル検証: linux/arm64のDockerfileビルド・実Node/Brotli検査が成功。各イメージで正常HTTPS接続成功、問題証明書2経路をCERT_REVOKEDで拒否。実サイトの公開確認・amd64での検証は未実施。
